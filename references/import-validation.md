BART 分组采用 `1+2`、`3+4`、`5+6`、`7+8`、`11+12`、`19+20`；全部保存来源线路 ID、模式与班次引用，不按同色/同名自动推断。HSL 所选线路在本次 feed 中没有线路颜色，因此初稿采用明确标注的备用配色，不将红/蓝当作官方颜色。

HSL 开放数据页面要求按 CC BY 4.0 署名并注明数据交付时间，本次来源记录与图注保留了这些信息。BART 同样记录来源及时间；本次不在公共仓库重新分发两份真实 feed、站点数据或生成地图。下载记录中的摘要用于确认输入内容，不涉及反复查询 Git 提交状态。

## 验证方式与结果

- 两份 ZIP 均通过下载记录→线路筛选→GTFS 导入→布局→绘图 JSON/SVG→librsvg PNG 的完整流程；后续排版迭代复用已保存的拓扑，避免反复扫描大型 feed。
- 原文站名与父站/子站来源 ID 按原始 `stops.txt` 核对。每条视觉线路抽取一个来源班次，按原始 `stop_times.txt` 数值顺序、上下客限制与父站身份核对站序；抽样不等于人工逐项审阅所有班次。
- 查看全图及密集区域。改进了站点间距、共享站间的分色错开及标签候选。最终自动结果仍是初稿，尚不能直接称为出版级地铁图。

## 虚构样例与兼容性

随包新增站序 CSV 有 7 站、3 线、4 个模式，包括支线、环线、共享身份和中英文。它没有经纬度或绘图坐标，生成非地理初稿。手册命令已实跑，生成的 JSON/SVG 与提交预览一致；原有五份绘图模板继续一致。

公开包包含 62 项测试：55 项标准库检查与 7 项可选 librsvg 像素检查。覆盖父站、同名异站、数值站序、方向/支线/环线/区间模式、服务日期例外、非乘客停站、换乘限制、非法引用、下载记录、CSV、分组、确定性布局、排版覆盖、命令行输出保护，以及原有 SVG/底图功能。开发目录还保留 4 项 Illustrator 准备阶段测试；它们与延期文件一起排除在公开包之外。

本次环境为 Linux/Python 3，使用 librsvg/Pango 与现有系统字体。Windows、macOS、CairoSVG 和 Illustrator 原生环境没有本轮实测。没有 librsvg 时 7 项像素检查会明确跳过，不能将跳过称为通过。

## 保留的能力边界

没有内置全球来源数据库、通用网页爬虫或 OSM 导入器；网页数据由 Agent 整理为统一输入。没有自动抓取底图或敷设方式，没有自动补译。布局不是严格 45°求解器，未测任意大规模网络的性能。来源许可、时效、换乘语义和视觉交付仍需按任务核对；后续方向见[改进计划](roadmap.md)。
