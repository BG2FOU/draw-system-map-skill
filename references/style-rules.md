# 换乘、敷设方式与站点样式

本页明确厦门地铁线网图风格中可复用的制图规则。规则有默认值，但不绑定城市、站数、固定线路颜色或交通类型；用户的明确风格要求优先。

## 普通站、换乘与预留站

- **普通站：** 白色/画布色内底，线路色描边圆，默认半径 5.5。
- **两线换乘：** 共用一个圆心与白色衬底，上、下两个独立半环箭头分别使用所属线路色。默认圆弧半径 12.5；箭头与弧线均可编辑。
- **三线换乘：** 三个独立箭头按 0°/120°/240°旋转分布，即上、右下、左下；更多线路等角分布。颜色不是全图统一的固定顺序，应按来源或构图要求指定。
- **颜色方位：** 默认按 `routes` 中线路顺序，站点的 `transfer_order` 可覆盖，必须恰好包含所有服务该站的线路 ID。例如三线 `['line1','line4','line6']` 分别对应上、右下、左下；两线则对应上、下。
- **备用样式：** `style.interchange_style: "ring"` 改为多色圆环；默认 `"arrows"`。圆环从顶部起按顺时针色段排列，其颜色方位与箭头样式不同，切换后应查看。
- **预留/未开放：** 站点设置 `status: "reserved"` 或 `"unopened"`；普通节点用灰色虚线圆，换乘箭头用灰色，站名同灰色且透明度 0.65。默认灰色为 `#858b91`，可用 `style.reserved_color` 改变。状态不会自动改动轨道颜色或敷设方式。

同一站点只绘一份符号及名称，不靠放大节点掩盖线路错位。普通交叉不生成换乘。对于多个独立站之间的步行换乘，先保留各自 ID，再按用户要求扩展连接符号，不擅自合并成同一圆心。

## 地下、地面与高架

默认地铁制图约定：

| `structure` | 含义 | 默认 `pattern` |
| --- | --- | --- |
| `underground` | 地下区段 | `solid`，线路色实心线 |
| `surface` | 地面区段 | `hollow`，线路色外框 + 白色内芯 |
| `elevated` | 高架区段 | `hollow`，线路色外框 + 白色内芯 |

内芯与外框使用**同一条完整路径**，圆角、曲率与端点一致，不能另画一条错位折线。内芯宽度是外框的 48%，使用圆头结束：圆帽会从几何端点向外延伸半个内芯宽度。同一线路先绘制所有区段的外框，再绘制内芯，避免相邻实心段的圆头遮住内芯；分段顺序和路径方向反转不改变转换处外观。空心内芯由 `style.hollow_fill` 控制，默认白色；并非透明挖空。

先从可靠输入确定结构类型和转换位置。未知位置留待确认，不根据城市经验或线路种类虚构洞口。`structure` 与开放状态是独立信息，预留站不自动把相邻线路改成虚线或灰色。

### 同一线路在站间转换

```json
{
  "id": "line-a", "name": "A 线", "color": "#D8443C",
  "segments": [
    { "points": ["west", [300,310]], "structure": "underground" },
    { "points": [[300,310], "central", [500,310]], "structure": "surface" },
    { "points": [[500,310], "east"], "structure": "underground" }
  ]
}
```

两个边界坐标属于区段端点，不属于站表，不增加车站。相邻段必须共享同一边界，保持方向连续。独立工具在各区段内计算圆角，因此切分点应放在直线段；若转换点必须在圆弧内部，先在项目绘图实现中按同一几何路径切分，不能用额外折点模拟。

### 自定义映射与优先级

其他交通方式或风格可以覆盖映射，例如地面单线、高架空心线：

```json
{
  "structure_patterns": { "underground": "solid", "surface": "solid", "elevated": "hollow" }
}
```

这段可放在全局 `style` 或单条 `route` 内；线路映射优先于全局。自定义结构名称也可加入映射。

区段样式选择顺序为：**区段显式 `pattern` → 区段 `structure` 对应映射 → 线路默认样式**。线路默认样式本身按 **线路显式 `pattern` → 线路 `structure` 映射 → 实线** 确定。未映射的结构名称需要补充映射或显式样式，不能静默猜测。

## 图例与版式

图例要同时解释线路色、实际使用的地下/地面/高架线型，以及普通、换乘、预留符号。自动图例只列线路，要用 `legend.items` 添加其余类别：

```json
{
  "items": [
    { "name": "地下段", "structure": "underground" },
    { "name": "地面 / 高架段", "structure": "elevated" },
    { "name": "普通站", "symbol": "station" },
    { "name": "两线换乘", "symbol": "interchange", "colors": ["#D8443C", "#247BA0"] },
    { "name": "三线换乘", "symbol": "interchange", "colors": ["#D8443C", "#247BA0", "#238B57"] },
    { "name": "预留站", "symbol": "reserved" }
  ]
}
```

线型行也可设置 `pattern` 和 `color`。图例符号使用与图面相同的渲染函数。换乘符号比普通站大，标注需要留足净空；双语文字不能压住箭头或被误认到邻站。
