# 适用于不同城市和网络的绘图方法

## 厦门地铁线网图风格

将其作为视觉参考时，重点借鉴圆角折线路径、稳定的线路色、清楚的换乘节点、中英文层级和留白。需要时加入浅色示意海域、灰色标题条及强调色下沿；主标题、配色、语言和地域轮廓仍由目标城市决定。

自带工具提供圆角线路、双色/三色换乘箭头、可选多色换乘环、预留站、地下实心线、地面/高架空心线和双语标注。具体约定见 [style-rules.md](style-rules.md)。特殊标题条和交通图标可在生成器/可编辑 SVG 中按参考扩展；不声称默认模板逐像素复制某张厦门地图。用户指定其他风格时采用该风格。

## 先确定连接，再安排位置

先建立节点与线路的逻辑关系：站序、分支从哪里分出、环线如何闭合、哪些站点共用身份、哪些线路只是交叉。图面的左右上下可以为了可读性调整，但不能因此改变连接或站序。同名不同站和相邻独立站不自动合并。

城市数据、交通类型和图例语义来自查得的可靠来源或用户资料。

可先用[导入生成器](import-guide.md)提取 GTFS/网页整理数据中的站序和身份，再生成初稿。完整经纬度产生大体方位布局；缺坐标时使用非地理拓扑布局。自动密度调整与共享边错开只提供起点，复杂交会与长站名仍需精修。站点/标签/路径修订保存为覆盖文件，底图等深度样式回写绘图 JSON。不要复制另一个城市的站数、固定配色、标题、双语译法、换乘箭头或结构状态规则；示例只展示数据结构。

## 构图与几何

先安排主干和重要枢纽，再布置支线与环线。按信息密度选择横向、纵向或方形画布；先给标题、图例和边缘留空，再安排站点。不必固定使用 45°网格，优先服从参考风格；使用折线风格时保持少量一致的方向和转角半径。

转弯控制点与站点分开，尽量使站点位于直线段。自带工具在控制点处生成相切圆弧，并限制相邻转弯的裁切长度；若参考要求其他曲线，可在项目自己的生成器中实现。多条线路共线时，通过独立路径形成可辨的平行线，共用换乘节点仍保持正确关联。

底图的方法与数据契约见 [basemap-guide.md](basemap-guide.md)。分开行政范围与自然地理，先固定跨水关系，再简化轮廓；示意坐标不表示真实距离。没有地理背景需求时使用清洁底色。

## 标注与视觉层次

保留来源中的名称、语言、大小写与标点。主语言和次语言的字号形成稳定层级；单语言网络不加多余翻译。标签在站点附近，长名字可通过布局留白、分行或定向偏移处理，避免让文字看起来属于邻站。

线路、普通站、换乘、文字和背景应有明确层次。默认地下实心、地面/高架空心，其他语义由输入覆盖并在图例说明；不能仅凭某种交通工具推断敷设或开通状态。站点不能被背景或轨道覆盖；跨线但不换乘的位置必要时添加可辨的局部衬线。

自带工具是基础生成器，复杂图标、自定义换乘符号、独立分区标签或特殊图例可以用可编辑 SVG 分组扩展；不要将整幅图栅格化后包装成 SVG。

## 迭代交付

先生成骨架，核对本次数据表达，再调整密集区域，最后渲染输出。查看全图的构图和裁切，再放大枢纽、分岔、环线接头、长站名与图例。自动生成成功不意味着文字没有碰撞。

只做通用数据检查和本次请求必要的视觉核对，不要求任何预置城市的专项检查器。修正问题应回到源数据或绘图代码，保留可重生成的 SVG；PNG 用于预览与分享，不承担可编辑源的角色。

字体与 PNG 渲染器可能影响文字度量；记录实际使用的渲染器，换字体后重新查看。没有 PNG 渲染环境时，可先交付 SVG，明确哪项导出尚未完成，而不是把 SVG 改成无法编辑的位图。

当前交付格式为可编辑 SVG 与 PNG。Illustrator 原生工程导出见[后续改进计划](roadmap.md)，本次发布不要求运行 Illustrator。
