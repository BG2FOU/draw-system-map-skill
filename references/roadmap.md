# 后续改进计划

更新日期：2026-10-30。

## 本次发布范围

已发布能力以源 JSON → 可编辑 SVG → 可选 PNG 为主，包含通用线路与换乘样式、地上/地下/高架区段，以及行政区、陆地、岛屿、水域、河流和独立地理标签。提供五份绘图模板和新增站序导入示例，不依赖城市或交通类型专项校验。

新增来源下载、GTFS/站序 CSV/拓扑导入、显式方向线路分组、确定性走廊骨架、沿走廊均匀布站、连续共线车道、符号净空与标签归属候选、冲突报告、独立排版覆盖。自动骨架采用水平、垂直和 45° 方向；同线有序子模式可复用显示路径，原始停站模式仍完整保留。Agent 可按国家/城市查找官方来源；不是全球自动数据平台，自动结果仍需图面检查。实际范围见[来源验收](import-validation.md)。

## 数据获取与布局的后续改进

1. 增加常用官方 API 的来源适配器与来源目录，记录许可、数据时效和线路覆盖；保留人工复核入口。
2. 实现 OSM 公共交通关系导入，处理 stop/platform 去重、stop_area、方向、缺失站序及服务覆盖。
3. 在已有 0°/45°/90° 骨架和连续共线车道上，提升复杂枢纽的分支排序、交叉处理与短转角过渡；补充字体实际测量、长站名换行和可视化拖动修订。
4. 支持更明确的换乘语义、站间步行连线、多语言来源字段，以及按需区分干线/区间/快慢车显示。
5. 补充更多国家、文字系统及超大 feed 的测试；继续区分已验证样本与工具理论适用范围。

这些是后续候选，不宣称本版已完成。
